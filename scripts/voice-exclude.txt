# 检查豁免清单（供 scripts/voice.mjs 使用）
#
# 作用：把「本来就没有对应语音/资源」的条目列入这里，检查与清单不再为其报告：
#   - 无后缀条目（技能）：gen 不再预留「缺音频（待补）」空位、reorganize 移除其残留条目、
#     write 跳过其台词行。适用于 mod技 / 内部子技 / 封锁技 / 链驱动等纯机制型技能。
#   - <角色id>.die：该角色的阵亡语音不进检查（gen 不列占位、write 跳过其 ~ 台词行）。
#   - <角色id>.bgm：该角色的 BGM 配齐检查跳过（用于「太阳神源侧与仓库均无、留空」的角色）。
#   - <角色id>.all：整个角色——技能 + 阵亡 + BGM 全部豁免（技能语义同无后缀）。
#
# 格式：每行一个条目；支持 * 通配（如 bts_sk_*_blocker）；# 起注释（整行或行尾）；
#   空行忽略。剥去后缀后需以 bts_ 开头（防误配）。
# 管理：`node scripts/voice.mjs exclude` 交互菜单；或 `exclude list|add|remove [id…]`；
#   也可直接编辑本文件，之后重跑 `node scripts/voice.mjs gen` 生效。
#
