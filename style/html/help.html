《崩铁杀》（星穹铁道·三国杀）是《太阳神三国杀 V2 EX》同名扩展的无名杀移植版：80 余名角色分布于 8 大阵营，在无名杀基础规则之上追加了怒气、必杀技、护盾、诅咒、异常、祝福与元素等自定义机制，并附带在线更新、推荐设置、AI 选将等扩展功能。

快速开始

  • 启用扩展：将「崩铁杀」放入无名杀 resources/app/extension/ 目录，在「选项 → 扩展」中启用并重启；已启用过旧版的可在扩展设置中点「在线更新扩展」获取最新版本。
  • 应用推荐设置：扩展设置 →「应用推荐的无名杀全局设置」，载入适配本扩展的全局配置（Windows/Android 两套，可先备份当前配置）。
  • 开始游戏：任意模式均可使用本扩展角色；身份模式单机局可额外配置 AI 选将策略与「主公星启」条件。
  • 疑难查看：选中角色或悬浮标记、词条（带下划线的名词）即可查看解释；本文即完整机制文档。
新手推荐流程：① 启用扩展并应用推荐设置 → ② 在扩展设置中开启「技能详情弹窗宽度加倍」「卡牌上显示出牌信息」（阅读辅助，按需） → ③ 开一局单机身份模式，遇到不认识的术语就悬浮或点击查看词条 → ④ 操作不熟练时先读无名杀基础操作。

无名杀基础操作

这一节写给从未玩过无名杀、甚至没玩过三国杀类游戏的玩家。已经熟悉的可以跳过。

点击展开阅读：从开局到出牌的操作指引

开始一局

  1. 主菜单点「开始游戏」，选择模式；初次游玩建议单机「身份模式」（主公/忠臣、反贼、内奸三方对抗）。
  2. 进入选将界面后，点击你想要的武将卡选择自己的角色；崩铁杀角色按势力分组，可先在界面里翻找。选好后点「确定」。
  3. 对局按座位轮流进行；轮到你的回合时，界面会逐段给出提示与可选按钮。

回合与出牌

  • 一个回合大致按「判定 → 摸牌 → 出牌 → 弃牌 → 结束」推进：开始通常摸两张牌，出牌阶段可以使用牌，手牌超出上限时需弃牌。
  • 点击手牌即可使用或打出；需要选择目标时，点其他角色，再点「确定」——点「取消」可以重选。
  • 基本牌（杀、闪、桃、酒）、锦囊牌与装备牌的使用方式与三国杀一致；本扩展不添加新卡牌，使用无名杀标准牌堆。

技能与必杀技

  • 你的技能按钮就在角色卡旁：满足发动条件时按钮会亮起，点击后按提示选择目标或牌，再点「确定」。
  • 崩铁杀的必杀技平时不会亮，攒足怒气后按钮亮起即可发动；技能描述里的名词（怒气、护盾、异常等）都可以点击查看解释。
  • 不确定点哪里时：悬浮（移动端长按）角色卡与技能按钮可以查看描述。

界面上的信息

  • 角色卡旁的角标就是崩铁杀的状态标记（怒气、护盾、异常、祝福等）；悬浮（移动端长按）可看层数，点击可看完整说明。
  • 屏幕角落的菜单按钮里有「托管」（交给 AI 自动行动，随时可以收回）、投降与退出等选项。

遇到问题

  • 操作被拒绝：通常是不满足使用条件（距离、次数、目标合法性等），说明区会给出原因。
  • 吃不准规则时：先把这一局打完，或退回主菜单重开；崩铁杀的大多数术语都能点击查看解释。

联机方法

联机功能目前尚不稳定，如遇问题请截图异常现象反馈。

  1. 进入联机模式：如果游戏界面有「身份」「国战」选项，可直接点击「联机」进入；如果没有，按屏幕中间偏左侧的按钮 → 左上角弹出「选项」按钮 → 左侧「联机」→ 点击右侧红色的「启」按钮进入联机模式。
  2. 连接服务器：如果联机地址处有 n.stlux.art 字样，直接连接即可；如果没有，按屏幕中间偏左侧的按钮 → 右上角弹出「联机大厅」按钮 → 点击进入联机大厅。
  3. 创建 / 加入房间：在联机大厅可以创建房间，设置好后点红色「启」按钮进入等待界面，其他玩家即可在大厅中看到你的房间；人数不足时由 AI 自动补齐，点击「开始游戏」即可正式联机。

联机昵称与头像

  • 在「选项」→「联机」处可设置联机时显示的名称和头像。头像输入你想显示的角色名即可；如果导入了崩铁杀扩展，也可以输入崩铁杀的角色名。
  • 建议不要保留默认的「无名玩家」，否则容易进错房间。
该服务器为其他无名杀玩家搭建，非官方服务器，稳定性无法保证。

基础机制

以下机制适用于崩铁杀角色，由扩展的全局规则与角色技能共同驱动；具体到某个角色是否涉及，以其技能描述为准。

怒气

  • 释放必杀技与部分主动技能的资源。受到伤害后回复等量怒气（受致命伤害时不回复）；造成暴击伤害时来源回复1点怒气；部分技能效果也会回复或消耗怒气。
  • 仅拥有「以怒气发动的必杀技」的角色会获得怒气（资源型必杀技角色不显示怒气）；「怒气豁免」可使消耗怒气时优先消耗豁免层数。
  • 是否在角色旁显示怒气层数可在扩展设置中开关。

必杀技

  • 角色的强力技能，消耗怒气（部分角色为火种、残梦等其他资源）发动，无次数限制，仅受资源门槛制约。
  • 处于星启状态时，必杀技伤害+1（部分技能另有额外效果）。

护盾

  • 独立的防御层数，受到伤害时每点护盾可抵挡1点伤害；贯通伤害可无视护盾。
  • 这是本扩展自有的机制，与无名杀本体的「护甲」互不相通：护盾只按上述规则抵挡伤害，不参与护甲的获取与回复。

诅咒

  • 受到伤害时，伤害+诅咒层数，并清空全部诅咒层数；诅咒不会被自然衰减。

伤害性质

性质 效果
致命伤害 受伤者不会因此回复怒气。
贯通伤害 无视护盾（护盾不参与抵挡）。
暴击伤害 伤害来源回复1点怒气（受击方被「石化」时受到的伤害视为暴击）。
通常伤害 技能标注“通常伤害”的伤害，不被致命/贯通/暴击等祝福改写。

伤害性质的来源：伤害性祝福（致命/贯通/暴击祝福）、技能自带标注、异常状态（石化）。多个性质可以叠加。

元素系统

元素共 7 种（显示与崩铁官方命名一致）；技能可为角色附加元素（标记显示为“xx附加”），也可造成带元素的伤害。

元素 标记名 融合触发
物理 物理附加 石化
炎 炎附加 烧伤
霜 霜附加 冻结
电 电附加 —
风 风附加 中毒
量子 量子附加 睡眠
虚数 虚数附加 麻痹

规则

  • 附加：对无元素者附加 → 直接挂上元素标记。
  • 同元素融合：对已附加相同元素者再次附加 → 移除元素并触发融合异常（对应上表；电暂无融合异常）。
  • 异元素替换：对已附加不同元素者附加 → 回复1点体力，并替换为新元素。
  • 元素相克：带元素的伤害命中附加了另一元素的角色时，该伤害+1，并移除其元素附加。
  • 本扩展元素不参与无名杀本体的铁索连环传导（束缚状态），改为自研的「伤害链」记录。

异常状态

由技能效果赋予，以层数计算；回合结束阶段开始时各减1层；回复体力会清除烧伤/麻痹/中毒/冻结/石化/睡眠六种基础异常（一次全部移除）。

异常 效果
麻痹 额定摸牌数-1；摸牌阶段开始时受到1点无来源伤害；引爆时每层造成1点无来源伤害。
烧伤 出牌阶段开始时受到1点无来源伤害；攻击范围-1；引爆时每层造成1点无来源伤害。
中毒 手牌上限-1；弃牌阶段开始时失去1点体力；引爆时每层使持有者失去1点体力。
冻结 造成的伤害基数-1；不能使用装备牌。
石化 受到的伤害视为暴击；不能使用锦囊牌。
睡眠 不能使用基本牌；其他角色与你距离-1。
混乱 造成的伤害无效。
恐惧 不能弃置牌。
地狱 你的手牌视为【决斗】；使用【决斗】时失去1点体力。
螺旋 所有角色不是你使用牌的合法目标（只能使用技能牌）；出牌阶段结束时移除全部。
体力上限减少 额外减少等同层数的体力上限（减少上限保底1点）；结束阶段开始时移除1层并回补。
「引爆」为部分角色的专属结算方式（如卡芙卡）；此外还有各角色专属异常（败谢、沉醉、揭露、命定等），可在对应技能与词条中查看。

祝福一览

附着于角色的状态标记，以层数计算；回合结束阶段开始时各减1层（标记为“常驻”的祝福除外）；部分祝福还会因特定效果被移除层数。

祝福 效果
致命祝福 你造成的伤害视为致命伤害（受伤者无法回复怒气）。
贯通祝福 你造成的伤害视为贯通伤害（无视护盾）。
暴击祝福 你造成的伤害视为暴击伤害。
不死祝福 防止你进入濒死（不消耗层数）；此祝福被移除至0层且体力小于1时，立即进入濒死。
体力上限祝福 每层使你的体力上限+1（若场上存在“雨过天晴”则翻倍）；衰减时上限随之下调。
星启祝福 视为处于星启状态，部分技能获得额外效果。
契约祝福 额定摸牌数+1。
治愈祝福 准备阶段开始时回复1点体力；若体力不大于1，每有1名存活且拥有“生机”的角色，回复量+1。
增幅祝福 发动必杀技造成的伤害+1；发动必杀技结算完毕后，若拥有至少2层，摸（层数-1）张牌。
赐福祝福 使用【杀】造成无属性伤害时，视为虚数属性伤害。
欢愉祝福 每层使你的欢愉成功判定成功率+10%。
此外还有各角色专属祝福（神君、生息、热意、雨过天晴、暗、海曲等），可在对应技能与词条中查看。

星启 · 忆灵 · 欢愉

星启

  • 主公星启：身份模式的主公默认常驻星启（可在扩展设置中调整启用条件：均启用/仅崩铁角色在场/仅崩铁角色为主公/不启用）。
  • 技能星启：由「星启祝福」层数驱动（视为处于星启状态），随回合结束自然衰减1层。
  • 效果：部分技能在星启状态下获得额外效果；星启角色发动必杀技时伤害+1。
  • 界面上统一显示为「星启」标记：悬浮可查看当前来源（主公/技能），来源可并存。

忆灵

  • 部分角色（阿格莱雅、遐蝶、风堇、白厄、长夜月等）可召唤忆灵并进入合体形态，体力与上限合并计算。
  • 生命同步：本体受到伤害/失去体力时忆灵生命等量扣减；回复体力时等量回补（封顶忆灵上限，主公额外+1）。
  • 离场：忆灵生命归零自动离场并还原形态，同时触发各自的离场效果（如回怒气、摸牌、额外回合）。

欢愉

  • 与角色“欢愉”技能（*_funny）联动的子系统：欢愉行动结算后获得1枚笑点。
  • 欢愉时刻：消耗全部笑点换算欢愉层数；每层使欢愉成功判定+10%（部分技能另有特殊联动，如“热意”替换为欢愉）。

其他全局规则

  • 伤害链 / 治疗链：系统自动记录“你伤害过谁（累计值）/为谁回复过体力”，供相关技能判定“伤害过你的角色”“你治疗过的角色”等条件；记录随技能消费或回合清理更新。
  • 回合计数清理：技能内部“本回合内有效”的计数（如素裳·若水“本回合发动过必杀技”）会在出牌阶段开始 / 回合开始 / 回合结束时自动清理（按各自语义），不会跨回合残留。
  • 体力上限保底：所有减少体力上限的效果（体力上限祝福衰减、失上限异常、变身还原等）最多扣至 1 点，不会因失上限导致濒死。
  • 额外回合：部分技能可给予额外回合或额外出牌阶段（如知更鸟·合颂、白厄·燔世波次）。
  • 标记变更日志：资源/效果类标记的获得与消耗会写战斗日志；纯内部计数不写（不刷屏）。

对无名杀底层的扩展

除角色内容外，本扩展还在无名杀引擎之上追加/覆写了以下底层功能，它们对所有崩铁杀角色自动生效：有些在界面上一眼可见，有些在后台运行。

全局规则技能

  • 伤害规则：伤害开始（星启必杀+1、元素相克判定）与伤害结束（怒气回复、元素附加、伤害链记录、忆灵扣血、暴击回怒）的统一结算。
  • 回复规则：回复结束（清除基础异常、治疗链记录、忆灵回补）与失去体力结束（忆灵扣减）的统一结算。
  • 阶段规则：出牌/回合开始/回合结束时的“本回合计数”自动清理。
  • 衰减规则：回合结束阶段开始时，祝福/异常自然减1层（常驻祝福除外；体力上限祝福先于其他祝福结算，保证“雨过天晴”翻倍的正确性）。

标记生命周期（对标记读写的覆写）

  • 覆写了玩家标记接口（addMark/removeMark）：标记层数大于 0 时自动挂载对应展示技能（图标/文字角标 + 悬浮说明），归零时自动卸载。
  • 统一接管标记变更日志：资源/效果类保留，纯内部计数静默；单个标记可显式覆盖。
  • 星启标记由“来源”驱动：主公星启与技能星启并集显示，来源变化时自动重算。

自定义标记事件

  • 在标记读写完成（存储已变更）后，向全局派发 bts_mark_add / bts_mark_remove 事件，供效果类技能监听“某标记被移除”等时机，替代对引擎内建触发的依赖。

元素与势力注册

  • 7 种元素注册进引擎元素表（含名称/颜色/排序），并设置不参与铁索连环传导；属性伤害与附加状态均由扩展自管。
  • 8 个阵营注册进引擎势力表（含专属颜色与势力图标），选将界面按势力分组。

AI 系统

  • AI 选将：仅单机·标准身份模式，在引擎选将决策前按策略选出目标角色并放到引擎必读取的位置（不修改模式文件；设置切换后下一局生效）。取位按评分排名概率抽取（如 70%/15%/…），不再每局固定同一名；主公位允许本体武将，但体力项按引擎口径饱和计分，不会只挑高体力武将。
  • AI 防重试守卫：以“全局操作计数”判断 AI 是否在同一出牌阶段反复空转发动同一技能，命中后跳过该技能，防止卡死。

BGM 跟随与切换 / 界面增强

  • BGM 跟随与切换：身份模式开局切换为主公专属 BGM（无专属则随机对战曲），循环播放；非崩铁主公不干预。同时允许角色技能切换 BGM（如知更鸟的必杀曲、知更鸟·晴歌的和声曲），随开关一并启停。
  • 称号图标：角色称号“属性·命途·昵称”渲染为属性/命途图标，点击查看中文名。
  • 出牌注记：在打出的牌下方显示“xx对xx使用”“xx打出”等一行小字（含录像回放）。
  • 弹窗宽度加倍：技能/角色详情弹窗宽度按当前布局动态×2（可选设置）。
  • 势力名排版：武将卡右上角势力标签按字数自动换行。
  • 词条悬浮：术语（怒气、祝福、异常、元素等）可在技能描述中悬浮/点击查看解释，解释与本文一致。

引擎差异适配

  • 体力上限保底：本体规则在体力上限扣至 0 时直接判定死亡，崩铁杀统一保底至少 1 点。
  • 出牌阶段中止：以“当前运行中的出牌阶段事件”原生语义终止，避免污染下一回合。
  • 额外回合/阶段：以阶段插入实现太阳神 Lua 中的额外回合与额外出牌阶段语义。
  • 形态切换：角色变形（含忆灵合体与还原）时按规则继承体力、体力上限与技能状态。

常见问题（Q&A）

Q1：武将人物背后有一大块模糊的图案，是正常的吗？

这是由于其他 UI 类扩展使用了势力图标作为武将背景，小图标被强制拉大后导致的模糊，是正常的。目前未考虑对其他 UI 扩展的适配，不影响游戏功能，请见谅。

Q2：以前玩身份局时，主公的选将框里全是董卓之类的高血量武将，现在还这样吗？

已修复。旧版「AI 选将逻辑」的主公位评分把「体力上限」按线性计分——混开本体武将池时，兀突骨、董卓等高体力武将必然霸榜。现在体力项改按引擎自身的价值曲线饱和计分（超出正常区间的体力收益递减），取位也改为按评分排名概率抽取，各类武将都有机会；本体武将当主公属正常结果，不再需要改「纯随机」。

Q3：联机头像只有曹操吗？怎么换？

可以更换。进入「选项」→「联机」，输入你想显示的角色名即可（输入崩铁杀的角色名也可以）。如果发现输入后没有变化，试试直接输入数字「9」——如果会模糊匹配到「银狼LV999」则属正常。

Q4：游戏显示异常 / 联机掉线 / 进不去大厅？

请先截图保存异常现象，然后尝试重启应用。联机服务器为无名杀其他大佬自建，稳定性无法保证。

遇到任何无法解决的问题，请在群内 @作者 并附上：① 问题现象的截图；② 你的设备类型（手机型号 / 电脑系统版本）；③ 已执行的操作步骤。信息越具体，定位问题越快，感谢支持！
